🌐 ACA Transformadora - Loja Online

![ACA Logo](./logo.png)

Bem-vindo ao repositório oficial do projeto ACA Transformadora, um site de e-commerce moderno e responsivo desenvolvido para destacar os produtos e serviços da ACA - Ar Condicionado Automotivo.


🚀 Demonstração

Acesse o site online:  
https://cedu1.github.io/Projeto-aca/


✨ Funcionalidades

🌗 Tema claro e escuro (modo tech ACA original)  
🌍 Suporte trilíngue: Português 🇧🇷 | English 🇺🇸 | Español 🇪🇸  
💬 Integração direta com WhatsApp para compra rápida  
📱 Layout 100% responsivo (mobile-first, otimizado para celular)  
⚡ Performance leve e sem frameworks externos  
🧱 HTML5 + CSS3 + JavaScript puro  


🛠️ Tecnologias Utilizadas

HTML5 – Estrutura semântica e acessível  
CSS3 (Flex + Grid) – Estilo moderno e responsivo  
JavaScript (ES6) – Alternância de tema, idioma e integração WhatsApp  
GitHub Pages – Hospedagem gratuita e estável  


🧩 Estrutura do Projeto

/Projeto-aca  
├── index.html        (Página principal)  
├── styles.css        (Estilos do site - tema claro e escuro)  
├── script.js         (Funções de tema, idioma e WhatsApp)  
├── logo.png          (Logo ACA)  
├── bancotrans.png    (Imagem do produto 1)  
├── bancosoft.png     (Imagem do produto 2)  
├── bancoapoio.png    (Imagem do produto 3)  
└── README.md         (Este arquivo)


⚙️ Como rodar localmente

1. Clone o repositório:
   git clone https://github.com/Cedu1/Projeto-aca.git

2. Acesse a pasta do projeto:
   cd Projeto-aca

3. Abra o arquivo index.html no seu navegador:
   - Clique duas vezes sobre o arquivo  
   - Ou use a extensão Live Server no VSCode


🧠 Personalização

Para alterar o número do WhatsApp, edite a linha no arquivo script.js:

const numero = '554199653950';

Para mudar textos e traduções, edite o objeto "textos" no mesmo arquivo.

Para atualizar imagens, basta substituir os arquivos .png mantendo o mesmo nome.
